# 자녀 학원/숙제 자동 메시지 알림 봇

구글 시트에 학원 스케줄과 숙제를 입력하면, 텔레그램 봇이 자녀에게 자동으로 알림을 보내줍니다.

## 기능

- **매일 아침 요약**: 오늘의 학원 + 숙제 일정 발송
- **학원 출발 전 알림**: 출발시간 30분 전 알림
- **숙제 알림**: 저녁 시간에 미완료 숙제 알림
- **숙제 완료 체크**: 자녀가 `/done 수학`으로 완료 체크 → 구글 시트 반영
- **부모 명령어**: `/add`, `/today`, `/send`, `/status`
- **주간 리포트**: 매주 일요일 숙제 완료율 통계
- **공휴일/방학 처리**: 휴일 시트로 학원 알림 자동 제외

## 설정 방법

### 1. 텔레그램 봇 생성

1. 텔레그램에서 `@BotFather` 검색
2. `/newbot` 명령으로 봇 생성
3. 발급받은 **봇 토큰** 저장

### 2. Chat ID 확인

1. 자녀와 부모가 각각 봇에게 아무 메시지 전송
2. 브라우저에서 `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates` 접속
3. 각 사용자의 `chat.id` 값 확인

### 3. Google Sheets API 설정

1. [Google Cloud Console](https://console.cloud.google.com/) 접속
2. 프로젝트 생성 → Google Sheets API 활성화
3. 서비스 계정 생성 → JSON 키 다운로드 → `credentials.json`으로 저장
4. 구글 시트를 서비스 계정 이메일에 **편집자** 권한으로 공유

### 4. 구글 시트 준비

아래 5개 시트를 생성하세요:

**시트1: 학원_고정스케줄**
| 자녀명 | 요일 | 학원명 | 출발시간 | 메모 |
|-------|------|-------|---------|------|

**시트2: 숙제_주간계획**
| 날짜 | 자녀명 | 과목 | 내용 | 페이지 | 완료여부 |
|------|-------|------|------|-------|---------|

**시트3: 자녀목록**
| 이름 | 텔레그램_chat_id |
|------|-----------------|

**시트4: 설정**
| 항목 | 값 |
|------|---|
| 부모_텔레그램_chat_id | (부모 chat id) |
| 아침_발송시간 | 07:00 |
| 숙제_발송시간 | 19:00 |
| 학원전_알림_분 | 30 |
| 시간대 | Asia/Seoul |

**시트5: 휴일**
| 날짜 | 사유 |
|------|------|

### 5. 환경 변수 설정

```bash
cp .env.example .env
```

`.env` 파일을 편집하세요:
```
TELEGRAM_BOT_TOKEN=your-bot-token
GOOGLE_SHEET_ID=your-sheet-id
GOOGLE_CREDENTIALS_PATH=credentials.json
```

### 6. 설치 및 실행

```bash
pip install -r requirements.txt

# 테스트 발송
python main.py --test

# 실행 (24시간 상시)
python main.py
```

## 명령어

### 자녀용
| 명령어 | 설명 | 예시 |
|-------|------|------|
| `/done [과목]` | 숙제 완료 체크 | `/done 수학` |

### 부모용
| 명령어 | 설명 | 예시 |
|-------|------|------|
| `/add [자녀] [날짜] [과목] [내용] [페이지]` | 숙제 추가 | `/add 민준 내일 수학 문제집 p.30~35` |
| `/today [자녀]` | 오늘 일정 조회 | `/today 민준` |
| `/send [자녀] [메시지]` | 즉시 메시지 전송 | `/send 민준 도시락 챙겨!` |
| `/status` | 숙제 완료 현황 | `/status` |
